FV® Core es la matriz independiente que registra y gobierna los proyectos FV® como módulos separados.

## Regla de construcción

1. Cada módulo se registra de forma independiente.
2. Su manifiesto se valida automáticamente.
3. Solo se marca como funcional cuando existe código ejecutable y evidencia reproducible.
4. Las conexiones entre módulos se definirán posteriormente por el autor humano.

## Estado actual

Los módulos están incluidos en `modules/` y registrados en `core/modules.json`.
La validación estructural **no equivale** a una prueba funcional del negocio.

Arquitectura de evolución: **FV® Connector → FV® Core → FV® ERP**.
