## Regla de construcción

1. Cada módulo se registra de forma independiente.
2. Su manifiesto se valida automáticamente.
3. Solo se marca como funcional cuando existe código ejecutable y evidencia reproducible.
4. Las conexiones entre módulos se definirán posteriormente por el autor humano.
